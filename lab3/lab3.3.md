
# Лабораторная №3. Таблица решений.

### Пояснение правил (без рассрочки, R=N):
* `Правила 1–2`: Многодетная семья (M=Y) → основная скидка 12%.

  - Если нет дня рождения → 12%.
  - Если день рождения → 12% + 5% = 17%.

* `Правила 3–4`: Не многодетные, но пенсионер/инвалид (M=N, P=Y) → основная скидка 10%.

  - Без дня рождения → 10%.
  - С днём рождения → 15%.

* `Правила 5–6`: Обычный покупатель (M=N, P=N), но сумма ≥100k (C=Y) → основная скидка 3%.

  - Без дня рождения → 3%.
  - С днём рождения → 8%.

* `Правила 7–8`: Обычный покупатель, сумма <100k (M=N, P=N, C=N) → основной скидки нет (0%).

  - Без дня рождения → 0%.
  - С днём рождения → 5%.

* `Правило 9`: Рассрочка (R=Y) → 0% (все остальные скидки отменяются).


### Важные замечания:
 * Основные скидки (3%, 10%, 12%) не суммируются между собой – применяется наибольшая из тех, на которые покупатель имеет право.
 * День рождения даёт дополнительные 5%, которые прибавляются к любой основной скидке (в том числе к нулевой).
 * Рассрочка полностью отменяет любые скидки, включая день рождения.
